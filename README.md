# Model Context Protocol (MCP)

A hands-on repository exploring and implementing the **Model Context Protocol (MCP)** using Python and FastMCP.

## Topics Covered

- MCP Architecture: Host, Client and Server
- MCP Tools, Resources and Prompts
- JSON-RPC 2.0
- STDIO and Streamable HTTP
- Async Programming
- Progress Reporting and Long-Running Tasks
- JWT Authentication

## Projects & Implementations

### 1. Email MCP Server
- Send emails using Gmail SMTP.
- Integrate email functionality through MCP tools.

### 2. JWT Authentication for MCP
- JWT token generation using FastAPI.
- Token-based authentication.
- Protected MCP server implementation.

### 3. Notion MCP Server
- Search pages in a Notion workspace.
- Create new Notion pages.
- Integration with the Notion API.

## Tech Stack

- Python
- FastMCP
- FastAPI
- HTTPX
- Notion API
- Gmail SMTP
- Uvicorn
ands-on learning and implementation of MCP concepts, integrations, authentication mechanisms and AI agent connectivity.
